# Playbook: consumer software, developer tools and online services

- **Sources:** docs, API specs, release notes, public changelogs, GitHub issues/PRs, status pages, third-party integrations, review platforms (G2, Capterra, app stores), support complaints, code and tests.
- **If review sites are blocked:** use app-store reviews, GitHub issues, community forums and changelogs.
- Compare practical user jobs, price, deployment friction, privacy/security, accessibility, offline behavior, reliability and platform support.
- Separate frontend limitations from backend/server authority; check API rate limits, secret exposure, compliance and update maintenance.
- A wrapper, extension or integration is often better than a full rebuild.
