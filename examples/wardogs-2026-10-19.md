# FINDHOLE Report — WARDOGS (Bulkhead / Team17)

> **Example output.** Produced by the first test run of FINDHOLE (pre-0.1.0, deep mode, 9 web searches, 5 fetches, ~46k tokens of conversation). Findings are as of 2026-10-19 and will go stale; it is here to show the report format, not as current advice about the game.

- **Date / as-of:** 2026-10-19
- **Mode / target / version / audience:** deep (the pre-release default) · WARDOGS, Steam Early Access, Season 2 / update 0.2.0 (live 2026-10-15) · players and anyone considering building a companion tool or service
- **Decision:** WATCH. There is **no clear gap an outsider can build into right now**. One small, cheap check is worth doing (H-06).
- **Bottom line:** The real pain points are progression pacing after the Season 2 change, how hard the game is on new and solo infantry, and having no Linux or Steam Deck support. Only Bulkhead can fix those, because the game is server-authoritative and uses kernel-level anti-cheat. The third-party tool space (maps, loadouts, calculators, LFG, patch trackers) is already crowded. The only possibly open niche is helping new and solo players find the right community server, and nobody has shown that demand yet.

## 1. Scope and research coverage

**Assumption (labeled):** "Wardogs" means the 2026 tactical FPS WARDOGS (Steam app 1867240), not the 2013 film.

**Promise / expected / actual:**
- *Promised by the dev:* An Early Access 100-player, three-team zone-control shooter with a cash economy and seasonal wipes. Bulkhead was unusually blunt before launch: little new content during EA, mediocre FPS, weak controller support, harsh death penalties, player numbers expected to fall (mein-mmo, 13 Aug 2026).
- *Actual:* Huge launch (3M+ copies, ~425k concurrent peak). Steam reviews mostly positive, but the reported scores vary widely (57% → 78–81%) by date and source. Queue and server problems at launch were largely patched. The Season 2 progression change backfired, and the dev admitted it on 17 Oct.

**Sources accessed:** Patch-history aggregator (Insider Gaming), Season 2 patch-note coverage (Gfinity, MP1st, Metaforge), DualShockers on the dev's admission, mein-mmo on the "10 reasons not to buy" post, Steam discussion threads (new player, solo), Linux/anti-cheat coverage (wardogshub, bo3.gg, wardogs.best, GamingOnLinux), and community tools (Metaforge, WARDOGS Companion, XGamingServer map). Everything was checked on 2026-10-19.

**Unavailable / limits:** I couldn't read the official Steam announcement page directly, the ExitLag review page returned 403, Reddit returned no game-specific results, and Discord is closed to me. Review percentages come from secondary sources and contradict each other. I didn't count independent complaint volume. Evidence on the Steam threads is thin (low reaction counts).

**Counterevidence searched:** Positive solo-play reports ("60 hours strictly solo"), experienced players defending the difficulty as intended ("not a movement shooter"), and the dev's own warnings before launch (which make several complaints *deliberate trade-offs*).

## 3. Already filled — don't rebuild

- **Database, maps, loadouts, ballistics, artillery calc, LFG, server status, mobile apps:** [Metaforge](https://metaforge.app/wardogs/loadouts?mine=true) covers nearly all of it. [WARDOGS Companion](https://www.saashub.com/wardogs-companion) adds a loadout planner, artillery calculator, PC-requirements checker and live player count. [XGamingServer's map](https://xgamingserver.com/tools/wardogs/interactive-map) adds a cost-per-kill tier list and budget builder.
- **Patch history / troubleshooting / Linux status:** wardogshub.gg, wardogs.best, Insider Gaming and Dexerto wiki.
- **Server instability at launch:** Bulkhead fixed most of it in Sep–Oct patches.
- **Modding / gameplay patches:** Not viable. The game is server-authoritative with Elytra kernel anti-cheat. Rule changes go through **community server admin settings** (RCON, ping limits, infantry/low-level rulesets), and those already exist.

Building another wiki, map or loadout tool would just duplicate what's there in a crowded space.

## 4. Best remaining opportunities

### H-06 — Finding the right server for new and solo players (the only one an outsider can act on)
- **Pain:** New players get stomped by vehicles (H-02). The fix today is "join an infantry or low-level community server", but the browser hides servers through its filters, and server names don't reliably describe the ruleset.
- **Evidence for / against:** *For:* the games.gg filter bug write-up, the variance in Infantry Only rulesets, Discord LFG by mode. *Against:* Bulkhead's own 0.1.2 Deploy flow already routes players to these servers, limited-mode official servers are planned, and Metaforge has LFG and server status. **There's no direct evidence that players are asking for an external server finder.**
- **Cause hypothesis:** The game's discovery UI is weak and community rulesets aren't labelled. *Falsified if:* the Deploy flow already lands new players in the right servers, or no public server-query data exists.
- **Options:** adopt (point players at the Deploy flow plus Metaforge LFG), build (a tagged, ping-sorted community-server directory), or watch (wait for the official limited-mode servers).
- **Recommendation:** **WATCH, plus one cheap verification.** Don't build until the data is known to be accessible and demand is proven.
- **Scores (1–5):** Impact 3 (it helps the group most likely to quit) · Evidence 2 · Unmet need 2 (it may close soon) · Feasibility 2 (depends on a server-query API that hasn't been confirmed. Scraping inside the game or bypassing the client is off the table.) · Risk 4 (the dev's limited-mode servers could make it obsolete, and the EA API could change).
- **Minimum viable experiment (~1–2 h, estimate):** (1) Check whether WARDOGS servers answer the Steam master-server / A2S query or expose a public list. (2) See whether Metaforge's server status already shows ruleset and level caps. (3) Search the Steam discussions for "which server" / "low level server" threads from the last 30 days.
- **Acceptance / kill:** Continue only if *all three* hold: a public query source exists that's allowed by the ToS, Metaforge doesn't already show rulesets, and there are ≥5 independent recent requests. Otherwise kill.
- **Rollback / safety:** It's an external read-only site, so nothing touches the game client. Don't scrape the authenticated client, and don't do anything to the anti-cheat.

### H-01 / H-02 / H-03 — for players, not builders
These are dev-owned, so for these the action is *adopt or wait*:
- **New players today:** Use the Deploy flow → Infantry/Low-Level community servers. Early cash comes from reviving, spotting and driving. Use IEDs on Humvees, Talons or CIWS on helicopters (Steam thread advice).
- **Progression:** Wait for next week's dev vlog and possibly an earlier Season 3.
- **Linux/Deck:** Wait for a Proton statement. Don't use the anti-cheat-disabling launch flag (ban risk).

## 6. What could make this analysis wrong?

- **Sampling:** Reddit and Discord weren't reachable, so the complaint picture leans on Steam threads and press. Review % sources disagree.
- **Version drift:** Season 2 is four days old. The 16 Oct hotfix and next week's vlog may change H-01 and H-02 completely.
- **Missed solutions:** A Discord bot or server-list site could exist that I didn't find (finite search, as of 2026-10-19).
- **Demand vs. desire:** Even if H-06 is real, new players may simply leave instead of using an external site.
- **Access blocker:** If the servers expose no public query, H-06 is dead no matter how much demand there is.
